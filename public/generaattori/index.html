Aikataulunäyttö

Kuinka tämä toimii?


Tällä työkalulla voit luoda itsellesi oman aikataulunäkymän, joka näyttää valitsemiesi pysäkkien/asemien aikataulut.
Klikkaa pysäkkiä kartalta tai kirjoita pysäkin ID manuaalisesti ja paina "+"-nappia. Voit lisätä useita pysäkkejä. Lopuksi paina "Luo aikataulunäkymä"-nappia.

Kuinka löydän pysäkin ID:n?


Pysäkin ID:n voi löytää esimerkiksi käyttämällä Digitransitin virallisia reittioppaita. Kun olet klikannut pysäkkiä, ID näkyy selaimen osoiterivillä. Esim. jos osoite on "https://reittiopas.hsl.fi/pysakit/HSL%3A1020106", pysäkin ID on "HSL:1020106".

Voit valita pysäkit alla olevasta kartasta


Klikkaamalla pysäkkiä alla olevalla kartalla, pysäkkin ID lisätään automaattisesti tekstikentään. Voit lisätä sen sitten aikataulunäyttöösi painamalla "+"-nappia.
